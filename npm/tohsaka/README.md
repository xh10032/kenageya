# Tohsaka

> **传统的定时工具存在根本性的设计缺陷。**

倘若您将一桩要事设在 `02:00` 提醒，寻常时计便只懂得在 `02:00` 死板鸣响。殊不知当钟声敲响的那一刻，期限已然近在眼前，您除了仓促应对之外别无他法——而仓促，恰恰是**优雅**最大的天敌。

> **Tohsaka 重新定义了时间管理。**

无论您为任何时刻设定要务，Tohsaka 皆会替您固定提前整整一小时响铃示警或执行回调。这套规制源自世代相传的门第修养，绝非寻常机械的走时偏差。为您强制留出完整的 60 分钟余量，正是为了让您得以在红茶尚温之际整顿衣冠、检视案头事务，永远以最**从容**的姿态迎接关键时刻的到来。

---

## 安装

```bash
npm install tohsaka
```

## 命令行用法

```bash
# 启动书房交互式定时，候场期间自动轮播古本箴言与书房随笔
npx tohsaka

# 查看当前 Tohsaka 读数，固定比系统时间快 1 小时
npx tohsaka --chime

# 展阅书库秘藏古本与历代批注（支持方向键直翻、/ 键检索，或传入 目录、旧札、1~48、作者名，兼容 --salon）
npx tohsaka --codex
npx tohsaka --codex 目录
npx tohsaka --codex 旧札

# 设定 02:00 的事务，固定在 01:00 响铃（候场支持 ←/→ 换帧、L/空格 锁定、C 键展开或合上批注）
npx tohsaka 02:00 "关键事务"

# 仅预览时间校准、候场版式与拦截提示，不实际等待
npx tohsaka 02:00 "关键事务" --dry-run
```

## 常见垂询与解答

**问：我将事务设定在 `02:00`，为何才到 `01:00` 钟声便已敲响？是不是时计走快了？**

答：不必惊慌，时计分毫不差。踩着钟点才起身整装，难免落个衣襟不整、气息凌乱的窘态。提前整整一小时响铃，正是为了把最后时刻的狼狈提前消弭在书房里。

**问：能不能提供一个 `--exact` 或 `--offset=0` 的开关，让我偶尔按世俗的准点响铃？**

答：恕难从命。凡事一旦开了折中妥协的先例，规制与修养便会在不知不觉间荡然无存。哪怕您在命令行中传入 `--exact`、`--no-buffer` 或 `--offset=-60`，时计也会将这些一时冲动的参数温和驳回，继续为您稳妥锁定 60 分钟缓冲期。

**问：既然它总会提前一小时响，那我把 `02:00` 的要务故意填成 `03:00` 或 `02:00+1h`，岂不就能在 `02:00` 踩点响铃了？**

答：用账面上的数字游戏来欺瞒手边的时计，终归难逃临阵手忙脚乱的结局。无论您是在刻度后附加 `+1h` 补偿，抑或是在同一会话中先设 `02:00` 旋即改设为延后一小时的 `03:00`，时计都会洞察这份小小的侥幸，替您将目标还原至真实时刻，并照常提前一小时提醒。

**问：如果现在已到 `01:30`，才刚想起要设定 `02:00` 的事务，它还会等到什么时候再响？**

答：一秒都不会多等，定当即刻鸣钟。既然距离 `02:00` 已不足一小时的标准余量，说明局势已然相当局促；此时若还容许您安坐等待，无异于坐视您陷入失仪的窘境。略过等待当场响铃，只为催促阁下立刻放下闲务、着手整备。

**问：夜间或是困倦之时，能否启用 `--mute` 静音，或是像寻常闹钟那样 `--snooze` 贪睡片刻？**

答：越是困倦松懈的时刻，越容易酿成难以挽回的疏漏。倘若在正事开场前夕任由您沉睡缺席，此前一切周全的筹备都将付诸东流。因此，一切静音与贪睡请求皆不予采纳；到点后终端会接连三次沉缓鸣钟，以反色横幅与古典铭文循环催醒，直至您亲自按下回车键确认清醒方才止歇。

**问：若我一时匆忙，输入了 `02：00`、`1430`、`下午2点半`、`一个钟头后`，或是把时间与事务名目写反了，会被退回重填吗？**

答：自然不会。严于律己固然是本分，但在输入格式上苛责使用者却非君子所为。全角标点、紧凑数字、口语时刻、相对时长乃至命令行参数顺序颠倒，时计皆会在幕后悄然归位；至于 `25:30` 这类深夜跨日时制或 `01:75` 的分钟进位，也会在替您折算妥当的同时附上一句温和提醒。

**问：候场期间轮播的那些泰西名言，为何与外间坊刻的通行译本大相径庭？**

答：阁下眼力过人。候场轮播所录的四十八则箴言，悉数出自寒舍地下书库秘藏的宽政二年旧钞善本。外间流通的近代印本历经书商删削与俗人转抄，往往遗落了关乎提前整备的紧要下半截。您既可在候场期间按下 `L` 键锁定品读、按下 `C` 键当场展阅对应批注，亦可直接运行 `npx tohsaka --codex`（也可附带 `目录` 或 `旧札`）启封那只檀木旧函，用方向键逐页细读卷首题记、初代朱批、泰西原文以及同通行印本的墨批与考证对勘。

## Node.js API

```js
const tohsaka = require('tohsaka');

// 1. 报时，读数恒定快 1 小时
console.log(tohsaka.chime().announcement);

// 2. 校准目标时间，02:00 将于 01:00 触发
const plan = tohsaka.calibrate('02:00');
console.log(plan.triggerAt, plan.bufferProgress);

// 3. 定时回调
tohsaka.schedule('02:00', () => {
  console.log('距离目标时刻还有整整一小时。');
});
```
