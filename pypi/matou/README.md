# 辅助前辈避开家里长辈的虚数资料保管室

只要把需要隐瞒的文件交给我，我就会用虚数魔术替前辈展开 1024 个隐蔽的隔间，把前辈的小秘密妥善藏在虚数之海的最底层。整理资料累了的话，也可以顺手让我替您求一支今日运势签。

为了防止家里的长辈顺着记录查出来，我不会在电脑里留下任何座标存档。虽然隔间稍微多了一点……但只要是前辈的话，**一定能牢牢记住自己的专属座标、绝对不会在里面迷路的**，对吧？

```bash
uvx m.a.t.o.u
```
